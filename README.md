# Ecommerce TD



## Setup
1. clone repository: `git clone https://github.com/SantiagoPa/ecommerce-td.git`
2. install dependencies: `npm install`
3. run develop mode: `npm run dev`
4. run preview mode: `npm run build && npm run preview`
